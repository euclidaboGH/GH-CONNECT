# GreenHaven 0.246.0 — Pass 24: End-to-End Journey Orchestration

This release makes the Home experience more outcome-oriented by turning the existing GreenHaven journey into a visible, accessible progress model. The journey now shows all four foundations—identity, discovery, connection, and participation—so users can understand where they are rather than seeing only another isolated next-action card. The interface keeps one clear next move while making completed foundations visibly complete and keeping unfinished foundations directly actionable.

Attention semantics were also tightened. Group notifications are no longer automatically counted as both Messages and Communities when their metadata explicitly identifies community context. This keeps the unified attention layer clearer and reduces the chance of presenting duplicate urgency for the same underlying activity.

No database migrations were changed in Pass 24. Existing navigation, server-authoritative economy flows, marketplace protections, social systems, membership state, rewards, and community boundaries remain intact.

Full Next.js build/typecheck remains unclaimed until verification is performed under the project's required Node 24 runtime with the complete dependency installation.
