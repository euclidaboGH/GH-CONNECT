# GreenHaven 0.248.0 — Pass 26: Personalized Home Focus

Pass 26 makes Home more context-aware without turning it into an opaque recommendation engine. The new Personalized Focus layer derives useful next options from activity already available in the current session: messages needing attention, community invitations and activity, network state, profile completion, interests and participation. Each primary suggestion explains why it is shown, and secondary options remain visible so the member keeps control of the journey.

No fabricated metrics, guaranteed outcomes, investment claims or synthetic activity were introduced. No Supabase migration files were changed. The canonical navigation remains Home, Messages, Communities, Cart and Profile, with Wallet remaining an overlay.
