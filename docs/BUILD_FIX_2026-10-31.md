# GreenHaven 0.222.0 — Vercel Build Fix

## Failure observed
Vercel production build reached Next.js compilation and failed during TypeScript validation at:
`app/api/auth/webauthn/authenticate/verify/route.ts:73`

The bounded JSON parser result was not narrowed before reading the nested WebAuthn assertion, so TypeScript inferred the parsed value too narrowly (`{}`) and rejected `response.response.clientDataJSON`.

The same deployment also emitted a real module warning because `components/ghc/message-screen.tsx` imported `useSectionRefresh` from `@/lib/client/section-refresh`, while the hook is defined/exported by `@/hooks/use-section-refresh`.

## Fixes
1. Narrowed the parsed WebAuthn request body to the expected public-key credential shape before property access.
2. Normalized `clientDataJSON` through `String(...)` for bounded parsing/challenge extraction.
3. Passed the narrowed WebAuthn response to `verifyAuthenticationResponse` using its function parameter response type.
4. Corrected `MessageScreen` to import `useSectionRefresh` from the canonical hook module.
