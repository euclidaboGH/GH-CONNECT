# GreenHaven 0.223.0 — Massive Upgrade Pass

This pass begins the next product-hardening cycle from the 0.222.0 CI-fix source. It restores the canonical five-item primary shell (Home, Messages, Communities, Cart, Profile), keeps Discovery as a secondary/deep-link surface, and keeps Wallet outside the bottom navigation.

Profile/identity is upgraded as a practical ecosystem launchpad rather than a static biography. The owner profile now exposes a compact “Your next moves” matrix for Discovery, Messages, Communities, Marketplace, Rewards and Wallet, while retaining the existing server-authoritative identity/reputation, membership, completion, timeline, media history, communities, dashboard and activity systems. Discovery signals make configured interests and connection intents visible to the owner as an explanation of how relevance is shaped without exposing ranking formulas.

This is the opening pass of the broader massive-upgrade cycle. Subsequent passes should continue across discovery/search, messaging, feed/creator, marketplace/seller, wallet/membership, rewards/opportunities, trust/safety, accessibility, resilience and observability without replacing durable server-authoritative systems with client-only state.
