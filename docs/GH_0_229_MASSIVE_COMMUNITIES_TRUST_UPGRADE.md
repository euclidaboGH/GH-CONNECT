# GreenHaven 0.229.0 — Massive Communities & Participation Upgrade

This pass turns Communities into a more results-oriented participation surface.

## Product upgrades
- Added a cross-community **Your community pulse** action center.
- Aggregates board updates, chat unread activity, and governance join requests requiring review.
- Added **Needs attention** sorting so users can prioritize active obligations rather than manually opening every community.
- Added a contextual **Continue where attention is needed** action inside community hubs.
- Preserved the core product boundary: Community Board is durable content/governance; Community Chat is optional realtime conversation and remains accessible through Messages.
- Preserved owner-only chat creation, members/approval chat privacy, community membership independence from chat membership, moderation roles, polls, events, announcements, resources and governance.

## Product principle
GreenHaven should convert notifications into clear next actions. Community participation should feel organized and purposeful, not noisy.
