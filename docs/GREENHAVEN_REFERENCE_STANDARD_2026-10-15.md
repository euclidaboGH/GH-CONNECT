# GreenHaven Reference Standard — 2026-10-15

This build adopts the four supplied reference images as the visual standard for GreenHaven.

## Locked visual arrangement
- Bright GreenHaven application header with brand identity, search, notification/profile actions.
- Social feed is the Home hero: large identity row, readable post copy, immersive media, clear quality/comment/save/share actions.
- Green + violet are the principal interface accents; green remains the primary brand/action colour.
- Five-item bottom navigation: Home, Discover, raised Create, Messages, Profile.
- Create uses the raised green-to-violet gradient treatment from the reference.
- Wallet uses a strong green balance hero, primary money actions, assets, then transaction/activity content.
- Rounded white surfaces use restrained depth on a very light neutral background rather than a generic dashboard grid.
- Mobile remains the primary composition; larger screens widen naturally rather than emulating a narrow phone.

## Production constraint
The reference artwork contains promotional/example balances and reward figures. Those values were NOT hard-coded into the application. Existing server-authoritative wallet, Pi payment, GHC, curation, membership, marketplace, Supabase/RLS and authorization logic remains the source of truth.
