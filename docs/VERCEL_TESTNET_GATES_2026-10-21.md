# Vercel Testnet gates — set these (private unless noted)

```
GHC_TESTNET_UNLOCK=1
GHC_BUY_WITH_PI_ENABLED=true
GHC_ACTIVITY_REWARDS_ENABLED=1
GHC_CURATION_REDISTRIBUTE_ENABLED=1

```
