# GreenHaven 0.225.0 — Massive Upgrade Pass 3

## Communication quality and results-oriented UX

This pass upgrades Messages as a professional communication workspace rather than a simple chat list.

- Dedicated Requests inbox with visible request counts and a focused empty state.
- Conversation-specific draft persistence so unfinished messages survive navigation and return to the correct thread.
- Clearer inbox information architecture across All, DMs, Unread, Requests and Communities.
- Existing realtime reconciliation, read state, typing/presence, media uploads, replies, reactions, retry, moderation, marketplace-order context, pin/archive/mute and offline recovery remain preserved.
- Canonical five-item bottom navigation remains Home, Messages, Communities, Cart, Profile. Wallet remains an overlay.

The product goal is lower communication friction, safer unsolicited contact handling, and better continuity for users doing real work, commerce and community coordination in GreenHaven.
