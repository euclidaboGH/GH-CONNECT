# GH CONNECT — Product clarity (Step 2)

## Product layers

| Layer | What it is | Primary surfaces |
|-------|------------|------------------|
| **Identity** | Who you are on GreenHaven | Pi sign-in, profile, GH ID |
| **Social** | People & conversation | Feed, Discover, Messages, Matches |
| **Belonging** | Groups with structure | Communities (Board + member chat) |
| **Value** | In-app utility economy | Wallet, Rewards, Membership (GHC — not π) |

Bottom nav stays flat (≤5): Home · Discover · Create · Messages · Profile.  
Everything else lives under Profile with clear groups.

## Research basis

| Source | Takeaway applied |
|--------|------------------|
| Mobile IA 2026 | Flat structure; important actions ≤2 taps from home |
| Progressive disclosure | One primary next action; hide power features until needed |
| Instagram / Facebook | Feed + messages + profile; secondary tools under profile |
| Fintech super-apps | One **money/value** area — not scattered wallet/rewards/membership |
| Discord / Groups | Community = structured space (board) + chat, not a fake DM |
| First-session research | Meaningful outcome in under ~60s; 3 steps max |

## Home behavior

1. **Next best action** strip (priority): incomplete profile → messages needing attention → join community → discover people → soft “you’re set”.
2. **Social shortcuts**: People · Messages · Communities (not duplicate Discover cards).
3. First-session tips: Identity → Belong → Connect (dismissible).

## Value area

Profile → **Value** groups:

- Wallet (GHC balance)
- Rewards (earn GHC)
- Membership (VIP / boosts)

Copy explicitly separates GHC from Pi balances.

## Out of scope for Step 2

- Foundation env/Supabase (Step 1)
- Pi native share / staking (later)
- Full visual redesign
- Auth or ledger changes
