# GreenHaven 0.247.0 — Pass 25: Outcome-First Home

Pass 25 refines the Home experience around a single decision: what useful outcome should the member move forward next? The previous separate action and journey surfaces are consolidated into one outcome panel that combines the primary next action with the member's real foundation progress.

The panel is driven by existing state and does not introduce fabricated metrics, people, communities, rewards, sales, or activity. It preserves the existing journey model, canonical navigation, server-authoritative financial boundaries, and the five-item primary navigation: Home, Messages, Communities, Cart, Profile.

The release is a UI/experience refinement only. No Supabase migration is added or modified.
