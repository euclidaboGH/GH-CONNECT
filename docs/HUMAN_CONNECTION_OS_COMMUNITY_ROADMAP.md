# GreenHaven Human Connection OS — Community Roadmap

**Principle:** Communities are social *infrastructure* connecting people, activities, events, knowledge, services, and trust — not a final destination feed.

## Formal stack

```
Community → Identity → Purpose → Discoverability → Membership → Roles
         → Rules → Discussions → Events → Activities → Resources
         → Moderation → Notifications → Health → Trust → Lifecycle
```

## Completed foundation (#43–#49)

- Belonging, invites, hub, discussions, replies, likes, announcements
- Search join actions, pin/hide, activity digests (non-financial)
- Notification subtypes + in-process dedupe (durable proposal **not applied**)
