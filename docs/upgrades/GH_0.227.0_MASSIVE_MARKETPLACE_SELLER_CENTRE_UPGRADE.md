# GreenHaven 0.227.0 — Massive Marketplace & Seller Centre Upgrade

This release advances Marketplace from a listing surface toward a professional commerce workspace.

## Product outcomes
- Seller Centre command dashboard with active listings, open orders, attention-needed orders and completed orders.
- Direct seller actions for creating listings and managing seller-side orders.
- Protected checkout journey made explicit: server revalidation, durable order creation and lifecycle tracking.
- Cart remains multi-seller and multi-rail while GHC and Pi payment paths stay distinct.
- Existing trust, reviews, reports, delivery modes, saved listings and order conversations remain intact.
- Canonical navigation remains Home · Messages · Communities · Cart · Profile; Wallet remains an overlay.

## Authority
No client-generated seller metrics are presented as money or settlement. Pricing, inventory, orders, payments and commerce transitions remain server-authoritative.
