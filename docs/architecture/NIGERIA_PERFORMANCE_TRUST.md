# Nigeria-first performance, trust & privacy (PROMPT #50)

## Performance (low-end + intermittent networks)

1. **Home-first budget** — interactive feed before wallet/marketplace bundles.
2. **Lazy tabs** — Discover/Messages/Profile heavy panels on first visit.
3. **Images** — compressed, lazy, width-limited; avoid auto-play video on cellular.
4. **Offline** — Class D caches for community lists & drafts; financial actions require online ack.
5. **Skeletons** — never blank white on tab switch.

## Trust

- Verification badges only from server-approved state in production.
- Reputation cannot be bought with GHC.
- Match ≠ Connection.

## Privacy (NDPR-minded)

- Collect LGA/city for discovery/profile only with purpose notice in onboarding.
- No public wallet balances.
- Mute/block respected across feed, discover, messages suggestions.
