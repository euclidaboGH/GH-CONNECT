GH-CONNECT 0.330.4 — PHASE 3 PROFILE & PERSONAL DASHBOARD UPGRADE

This is a complete repository release based on GH-CONNECT 0.330.3.
The repository root contains app/, components/, lib/, supabase/ and package.json.

PHASE 3 SCOPE
- Separate social-first Profile presentation from personal identity/account management.
- Move Action Hub, Discovery Signals, identity overview, professional identity,
  achievements, pioneer identity and profile-completion tools into Personal Dashboard.
- Keep Profile focused on profile identity, relationships, timeline, media and social tabs.
- Add dashboard modal Escape handling, background scroll locking and safe-area scrolling.
- Preserve existing identity services, public-profile hydration and reputation authority.

DATABASE / BLOCKCHAIN
- No database migration is introduced by this UI architecture change.
- No Pi payment, wallet, GHC issuance, GHPV settlement, payout or ledger behavior is changed.
- Existing server-authoritative identity and reputation boundaries remain in force.
