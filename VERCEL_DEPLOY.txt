LOCAL REPOSITORY PREPARATION
----------------------------
1. Extract the archive to a dedicated folder; use the folder containing package.json as the repository root.
2. Confirm .env.example is present but no .env, .env.local, provider secrets, node_modules, .next, or .vercel files are staged.
3. Use the supported Node version, then run npm ci --legacy-peer-deps.
4. Run npm run audit:project-integrity, npm run typecheck, npm run lint, npm run ci:verify, and npm run build. Do not bypass checks or use ignoreBuildErrors.
5. Review actual CI output and the current migration inventory before pushing. A successful push is not production approval.
