# GreenHaven World-Class UI Standard — LOCKED

The four user-approved sample images are the visual source of truth for GreenHaven presentation.

## Brand system
- Primary green: #079447; deep green: #043D24; bright green: #10C767.
- Primary violet: #6D28D9; magenta accent: #D946EF.
- Ink: #17133B; canvas: #F7F7FC; surfaces: white; borders are low-contrast violet-tinted hairlines.
- Positive/upvote: green. Negative/downvote: #DF1662. Social utility and secondary emphasis: violet.
- Create is the only persistent green→violet→magenta gradient control.

## Composition
- Home is social-first: brand/search/notifications, then content. No dashboard wall before the feed.
- Posts are substantial white cards with identity → copy → immersive media → engagement → governed value/impact details when real data exists.
- Bottom navigation is Home / Discover / Create / Messages / Profile. Create is raised and visually dominant.
- Wallet order: header → green balance hero → primary actions → assets/activity. Real balances only.
- GHC Journey: journey identity → level/balance/XP → progress → streak/opportunities/missions. Real server-authoritative values only.
- Profile is identity-first; marketplace is photography/product-first; messages are conversation-first.

## Shape and depth
- Main cards: ~23px radius. Controls: ~16px radius. Pills only for status, compact filters, badges and chips.
- Shadows are soft and violet-neutral; borders remain subtle. Avoid nested card-on-card decoration without hierarchy.
- Mobile is the reference composition. Desktop adds breathing room and useful columns; it must not simply stretch the phone UI.

## Product integrity
The reference images contain illustrative balances/rewards and marketing copy. Never hard-code those examples into production. Pi, GHC, wallet, curation, membership, marketplace, Supabase/RLS and authorization remain server-authoritative. Never present guaranteed financial return, investment appreciation, mining/yield, or unsupported security claims.
